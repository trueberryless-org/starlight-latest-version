# `starlight-latest-version`

Starlight plugin to show the latest released version of your package in your documentation.

[![Netlify Status](https://api.netlify.com/api/v1/badges/6569e37d-d7af-49b6-8b28-cd85dbf73dab/deploy-status)](https://app.netlify.com/projects/starlight-latest-version/deploys)

## Documentation

Read the [Starlight Latest Version docs](https://starlight-latest-version.netlify.app).

## Package

If you are looking for the Starlight plugin package, you can find it in the [`packages/starlight-latest-version/`](https://github.com/trueberryless-org/starlight-latest-version/tree/main/packages/starlight-latest-version) directory.

## Project structure

This project uses pnpm workspaces to develop a single Starlight plugin from the `packages/starlight-latest-version/` directory. A Starlight documentation site is also available in the `docs/` directory that is also used for testing and demonstrating the Starlight plugin.
